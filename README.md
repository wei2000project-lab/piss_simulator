# Porcelain Playground · 小事練習室

一個 HTML、CSS、Three.js 製作的第一人稱 **3D 尿尿模擬器**。走進暖光白瓷的浴室，瞄準馬桶、放鬆出水，最後沖個乾淨。所有場景、材質與音效都由程式產生，不依賴外部圖片或 CDN。

## 啟動

**Windows：雙擊 `start.bat`。**

- 已安裝好本機相依套件，可直接啟動。
- 將專案複製到其他電腦時，首次啟動會自動準備 Node.js、Three.js 與 Electron，需要網路；之後可以離線遊玩。
- 不需要管理員權限。啟動器以專案資料夾為工作目錄，路徑可包含中文與空格。
- HTTP 伺服器僅監聽 `127.0.0.1`，透過 `listen(0)` 請作業系統原子分配空閒 port。關閉遊戲會關閉伺服器。
- 完整功能請由 `start.bat` 啟動。單純在一般瀏覽器開啟時，瀏覽器的安全限制無法保證原生游標定位或攔截關閉分頁快捷鍵。

## 操作

| 操作 | 功能 |
| --- | --- |
| W / A / S / D 或方向鍵 | 自由移動；有牆壁、馬桶、浴缸與家具碰撞 |
| Shift + 移動 | 加速 |
| Space | 跳躍，可跳上較低的家具 |
| 按住滑鼠左鍵 | 產生半透明、受重力影響的連續拋物線水柱 |
| 按住滑鼠右鍵 | **將系統游標真正固定在按下時的位置**，使用相對硬體位移旋轉視角；放開後釋放 |
| Ctrl | 切換持續旋轉視角；鎖定與解鎖時游標均在遊戲視窗中央 |
| F | 靠近馬桶沖水；也可按左側「沖個乾淨」 |
| C | 清除地板積水 |
| R | 補充至 1,200 ml |
| Esc | 暫停／繼續，同時釋放游標 |
| F11 | 全螢幕／視窗 |
| Ctrl + W | 在 Electron 主程序攔截，不會關閉遊戲 |

要離開遊戲，請按視窗標題列的 **×**。切到其他視窗、縮小、移動或改變視窗大小時會釋放游標；失去焦點會暫停遊戲。

## 玩法

按「走進浴室」開始。按住右鍵環顧，用 WASD 靠近馬桶，畫面中的淡色圓圈表示水柱的實際預測落點。落點在馬桶內時準星變成淡綠色。

水量會從補給存量扣除。水柱飛行後才計入命中量，放開左鍵後，已飛出的水仍會落地。射到外側、牆壁或家具的水會在地板累積成水窪；鄰近的水滴會合併，水窪隨水量擴張。水柱碰到陶瓷邊緣也會濺出。

小目標是 **300 ml 進入馬桶，再沖水**。沖水會呈現旋轉、下沉、回補的動畫及程序產生的音效，清掉馬桶中的水色；地板積水要另外按 C 清理。完成後可以繼續自由玩，或按「重新練習」。

左側顯示命中率、累計入桶量、目前地板積水及補給。累計入桶量在沖水後保留，方便看整次練習的成績；命中率包含已射出的水量，因此飛行中的水會讓數字短暫變化。

## 實作

- `index.html`、`style.css`：繁體中文介面、操作說明、狀態與小視窗排版。
- `src/world.js`：浴室建模、光照、陰影、程序磁磚與木紋、平面反射鏡。
- `src/physics.js`：拋物線、馬桶開口／邊緣／牆壁碰撞、玩家碰撞與落地判定。
- `src/fluids.js`：可更新頂點的透明水柱、飛濺粒子、波紋、漸進式積水。
- `src/game.js`：遊戲狀態、飛行中的水量、移動、跳躍、任務與 UI。
- `src/audio.js`：Web Audio 程序水聲與完成提示音。
- `desktop.cjs`、`preload.cjs`：Electron 桌面視窗、受限 IPC、快捷鍵攔截與生命週期。
- `native/CursorBridge.cs`：Windows `ClipCursor` 真實限制游標、`SetCursorPos` 定位、Raw Input 擷取相對位移。透過內建 Windows PowerShell 的 `Add-Type` 載入，不需額外安裝編譯器。
- `server.cjs`：僅供本機使用的動態 port 靜態伺服器。
- `bootstrap.ps1`、`start.bat`：一鍵啟動與首次相依套件準備。

不使用瀏覽器假的游標圖片。右鍵模式會把 Windows 裁切矩形設為當前游標的 **1 × 1 實體像素**，Raw Input 繼續接收硬體位移；Ctrl 模式先移至內容視窗中央。原生助手在標準輸入斷線時也會解除鎖定並退出。

## 驗證

純邏輯測試（有 Node.js 時）：

```powershell
node --test tests/physics.test.mjs tests/server.test.cjs
```

7 項測試涵蓋重力拋物線、入桶、地板、邊緣、牆壁與家具命中、移動防穿透、家具落地，以及兩個實例的獨立 port 與資產存取範圍。

`tests/desktop-check.cjs` 是本次開發環境用的 Playwright 桌面整合驗證，包含讀取 Windows 真實游標裁切矩形、Ctrl+W、跳躍、入桶計量、目標／沖水、地板積水、清理、補充、暫停、說明、重置與小視窗截圖。其 Playwright 路徑需依電腦環境調整。驗證畫面存於 `artifacts/`。

Web 預覽（僅供開發）：

```powershell
node server.cjs
```

在瀏覽器開啟終端機顯示的本機網址。完整六項原始要求請在桌面模式驗收。
