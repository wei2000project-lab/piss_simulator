# Porcelain Playground · 小事練習室

一個 HTML、CSS、Three.js 製作的第一人稱 **3D 尿尿模擬器**。浴室與客廳由可開關的木門相連，客廳右側延伸至開放式廚房，可以自由走動、瞄準馬桶、放鬆出水，再沖個乾淨。所有場景、材質與音效都由程式產生，不依賴外部圖片或 CDN。

## 啟動

**Windows：雙擊 `start.bat`。**

啟動後會直接進入全螢幕遊戲，沒有開始頁或二次開始按鈕。3D 畫面佔滿視窗，目標、數據、操作提示與暫停選單均在遊戲畫面內；按 H 可隱藏操作介面。

- 已安裝好本機相依套件，可直接啟動。
- 將專案複製到其他電腦時，首次啟動會自動準備 Node.js、Three.js 與 Electron，需要網路；之後可以離線遊玩。
- 不需要管理員權限。啟動器以專案資料夾為工作目錄，路徑可包含中文與空格。
- HTTP 伺服器僅監聽 `127.0.0.1`，透過 `listen(0)` 請作業系統原子分配空閒 port。關閉遊戲會關閉伺服器。
- 完整功能請由 `start.bat` 啟動。單純在一般瀏覽器開啟時，瀏覽器的安全限制無法保證原生游標定位或攔截關閉分頁快捷鍵。

## 操作

| 操作 | 功能 |
| --- | --- |
| W / A / S / D 或方向鍵 | 自由移動；有牆壁、馬桶、浴缸與家具碰撞 |
| Shift + 移動 | 加速 |
| Space | 跳躍，可跳上較低的家具 |
| 按住滑鼠左鍵 | 發射多段半透明拋物線水柱；各段獨立飛行，整段落下後才計入水量 |
| 按住滑鼠右鍵 | **將系統游標真正固定在按下時的位置**，使用相對硬體位移旋轉視角；放開後釋放 |
| Ctrl | 切換持續旋轉視角；鎖定與解鎖時游標均在遊戲視窗中央 |
| F | 靠近浴室門開關門；靠近馬桶沖水。畫面會顯示目前可執行的動作 |
| C | 清除地板積水 |
| R | 補充至 1,200 ml |
| H | 隱藏／顯示遊戲畫面內的提示與數據 |
| Esc | 暫停／繼續，同時釋放游標 |
| F11 | 全螢幕／視窗 |
| Ctrl + W | 在 Electron 主程序攔截，不會關閉遊戲 |

要離開遊戲，按 **Esc → 離開遊戲**，也可按 Alt+F4。F11 可以切回視窗模式。切到其他視窗、縮小、移動或改變視窗大小時會釋放游標；失去焦點會暫停遊戲。

## 玩法

開啟後即可遊玩。按住右鍵環顧，用 WASD 靠近馬桶。淡色地面圓圈表示實際積水的位置，包括碰到牆壁或家具後流下的水；落點在馬桶內時準星變成淡綠色。

客廳在出生位置後方：轉身走近木門，按 **F 開門**，即可穿過門口。客廳包含木地板、沙發、茶几、扶手椅、書架、電視櫃、窗景與落地燈；人物與水柱都會受到門、隔牆與家具的實際碰撞。門從兩側都能操作，會朝遠離人物的方向打開，關閉時會擋住通行；門扇碰到人物會停止並反向，避免把人物夾住。

客廳右側向外拓寬 5.5 公尺，整個客廳與廚房區域寬 12.5 公尺。沿原客廳右側走即可進入開放式廚房，包含 L 型櫥櫃與石材檯面、凹入式水槽與水龍頭、爐台與烤箱、抽油煙機、冰箱、中島、兩張吧檯椅、吊燈與香草窗台。木地板與磁磚區分兩個區域，畫面內會顯示目前位置；浴室保持原大小，牆外無法穿行。廚房檯面、冰箱與中島會阻擋人物和水柱，檯面上的水會沿邊緣流到地板後才形成積水。三個區域都能產生與清理積水。

水柱每秒發射 **60 段**，總流量保持 92 ml／秒，每段保留自己的出發位置、方向、速度及水量。轉向或移動只影響之後發射的水；放開左鍵後，已飛出的水段會繼續下落。每段頭部碰到表面後，還要等尾部一起落下才增加入桶量或積水。碰到牆壁、陶瓷邊緣或家具的水段，會繼續流向地板，真正到達地面後才產生積水。

積水保留每一塊實際覆蓋的形狀。兩攤水接觸時，顯示的是原有覆蓋範圍的聯集：重疊處只畫一次，兩側外形保留，不會突然換成一個大圓，也不會因連接而填滿原本乾燥的凹處。下落的水只有真的碰到某一塊積水的覆蓋範圍時，才增加那一塊的水量與面積；落在附近的乾燥地面會形成新的積水，其他未被碰到的部分不會自行膨脹。

小目標是 **300 ml 進入馬桶，再沖水**。沖水會呈現旋轉、下沉、回補的動畫及程序產生的音效，清掉馬桶中的水色；地板積水要另外按 C 清理。完成後目標面板會自動摺疊到左側，只留下「✓ ›」按鈕，點擊可隨時展開或再次摺疊。重新練習時面板恢復展開。

畫面左上角顯示目標、命中率、累計入桶量與目前地板積水，右下角顯示補給。累計入桶量在沖水後保留，方便看整次練習的成績；命中率包含已射出的水量，因此飛行中的水會讓數字短暫變化。

## 實作

- `index.html`、`style.css`：繁體中文介面、操作說明、狀態與小視窗排版。
- `src/world.js`：浴室建模、光照、陰影、程序磁磚與木紋、平面反射鏡。
- `src/living-room.js`：客廳建模、程序木地板、家具、窗景與照明。
- `src/kitchen.js`：開放式廚房、櫥櫃、水槽、爐台、冰箱、中島、磁磚與照明。
- `src/spaces.js`：相連房間的範圍、家具與隔牆碰撞配置。
- `src/door.js`：可雙向互動的旋轉門、開關動畫與防夾判定。
- `src/collision.js`：人物、水柱、積水共用的軸向／旋轉碰撞幾何。
- `src/physics.js`：預覽與實際水段共用的掃掠碰撞、拋物線、玩家碰撞與落地判定。
- `src/water.js`：各水段的獨立物理狀態、尾部落地、牆面／家具排水、發射頻率與水量守恆。
- `src/fluids.js`：單一 InstancedMesh 批次繪製分段水柱、飛濺粒子、波紋，以及單一地面遮罩材質。
- `src/puddles.js`：真實覆蓋範圍命中、水窪連通性、保留各分支形狀的聯集遮罩；重疊處取最大覆蓋率，不堆疊透明度。
- `src/game.js`：遊戲狀態、飛行中的水量、移動、跳躍、任務與 UI。
- `src/audio.js`：Web Audio 程序水聲與完成提示音。
- `desktop.cjs`、`preload.cjs`：Electron 桌面視窗、受限 IPC、快捷鍵攔截與生命週期。
- `native/CursorBridge.cs`：Windows `ClipCursor` 真實限制游標、`SetCursorPos` 定位、Raw Input 擷取相對位移。透過內建 Windows PowerShell 的 `Add-Type` 載入，不需額外安裝編譯器。
- `server.cjs`：僅供本機使用的動態 port 靜態伺服器。
- `bootstrap.ps1`、`start.bat`：一鍵啟動與首次相依套件準備。

不使用瀏覽器假的游標圖片。右鍵模式會把 Windows 裁切矩形設為當前游標的 **1 × 1 實體像素**，Raw Input 繼續接收硬體位移；Ctrl 模式先移至內容視窗中央。原生助手在標準輸入斷線時也會解除鎖定並退出。

## 驗證

純邏輯測試（有 Node.js 時）：

```powershell
node --test tests/physics.test.mjs tests/puddles.test.mjs tests/water.test.mjs tests/door.test.mjs tests/kitchen.test.mjs tests/server.test.cjs
```

35 項測試涵蓋重力與碰撞、獨立水段、每秒 60 段、不同幀率的水量守恆、水窪聯集、門的雙側操作、開關門時的人物與水柱碰撞、旋轉門扇的真實形狀、防夾反向、廚房來回通行、拓寬後的浴室與外牆邊界、廚具碰撞與排水、新增地板積水，以及本機動態 port 與資產存取範圍。

`tests/desktop-check.cjs` 是本次開發環境用的 Playwright 桌面整合驗證，包含讀取 Windows 真實游標裁切矩形、Ctrl+W、跳躍、入桶計量、目標／沖水、地板積水、清理、補充、暫停、說明、重置、開關門、三區域往返、廚具阻擋、廚房積水與小視窗截圖。其 Playwright 路徑需依電腦環境調整。驗證畫面存於 `artifacts/`。

Web 預覽（僅供開發）：

```powershell
node server.cjs
```

在瀏覽器開啟終端機顯示的本機網址。完整六項原始要求請在桌面模式驗收。
